# Iran Stock AI Agent

نسخه حرفه‌ای اولیه برای تحلیل نمادهای بورس ایران با محوریت TSETMC.

## اجرا
```bash
pip install -r requirements.txt
streamlit run app.py
```

## نکته
Endpointهای عمومی TSETMC ممکن است تغییر کنند. برنامه در صورت ناقص‌بودن داده، وضعیت NEEDS_REVIEW می‌دهد و داده ساختگی تولید نمی‌کند.
